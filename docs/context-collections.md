# Original-source context collections

Tools assemble copies of source chunks into product, general writing, voice,
channel, visual and uncertain/general collections. No document or saved plan is
rewritten. Each passage keeps its original text and citation ID; short references
connect collection membership to a single shared evidence dictionary.

Planning includes applicable visual constraints alongside writing and product
facts. Draft generation and revision select writing/product/channel context;
image selection selects visual/channel/general restrictions, including legal
sources. Unknown scope remains included. Explicit dependency IDs override normal
filtering so linked exceptions are not dropped. Classification uses source paths
and headings, rather than generating replacement guidelines with an LLM.

Each generation request includes its own asset brief. Stable source collections
precede changing decisions and copy. Verification retains original source access.
This grouping is conservative: unknown documents and mixed-scope chunks can still
be large. It is not a claim that all irrelevant passages are eliminated or that
quality is unchanged; equivalent completed campaigns still need comparison.
